# jot-jt.github.io

This template is adapted from <a href="https://github.com/keunhong/keunhong.github.io">https://github.com/keunhong/keunhong.github.io<\a>.

- Feel free to borrow this template.
- Make sure to update all relevant fields in `_config.yml` and `_data`.

## Theme preview tool

Run `bundle exec jekyll serve --config _config.yml,_config.preview.yml --port 4001`
and open [the theme picker](http://localhost:4001/theme-picker.html).
